# Nesplora estática

Esta pasta é uma cópia autônoma compilada da Nesplora, publicada pelo próprio deploy do Neuroped em `/nesplora/`. Os arquivos de mídia ficam em `media/`; não há dependência de URLs Manus em runtime. Para atualizar a cópia a partir do projeto-fonte, execute `node scripts/sync-nesplora-static.mjs` no repositório do Neuroped.
