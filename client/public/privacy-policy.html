NeuroPed Escalas

Política de Privacidade

Última atualização: 27 de março de 2026

1. Introdução

O aplicativo NeuroPed Escalas ("App") é desenvolvido e mantido pelo Dr. Jadson Fraga Araújo Júnior, médico neuropediatra inscrito no CRM-PE, com consultório em Petrolina-PE, Brasil.

Esta Política de Privacidade descreve como coletamos, usamos, armazenamos e protegemos as informações dos usuários que utilizam o App. Ao utilizar o NeuroPed Escalas, você concorda com as práticas descritas nesta política.

2. Dados Coletados

2.1 Dados Fornecidos pelo Usuário

  • Dados de autenticação: senha de acesso ao aplicativo (armazenada localmente, não transmitida a servidores externos)
  • Dados clínicos inseridos: respostas a escalas, questionários e inventários preenchidos durante o uso do App
  • Dados de pacientes: informações inseridas no prontuário clínico (nome, idade, dados de anamnese, medicações, evolução)

2.2 Dados Coletados Automaticamente

  • Informações do dispositivo: tipo de dispositivo, sistema operacional e versão do navegador (para otimização de desempenho)
  • Dados de uso: funcionalidades acessadas e tempo de sessão (dados agregados, não identificáveis)
Importante: O NeuroPed Escalas NÃO coleta dados biométricos, localização GPS, contatos do dispositivo, fotos, microfone ou qualquer dado pessoal sensível além dos explicitamente inseridos pelo profissional durante o uso clínico do App.

3. Uso dos Dados

Os dados coletados são utilizados exclusivamente para:

  • Gerar relatórios clínicos detalhados com interpretação por extenso
  • Enviar relatórios por e-mail ao profissional responsável pela avaliação
  • Gerar documentos em formato PDF para impressão
  • Armazenar prontuários clínicos para consulta posterior
  • Melhorar a experiência do usuário e o funcionamento do App

4. Envio de E-mails

Ao finalizar uma escala ou avaliação, o App envia automaticamente um relatório detalhado para o e-mail configurado pelo desenvolvedor (jadsonfraga@hotmail.com). Este envio é realizado via API segura (HTTPS) e contém apenas os dados da avaliação realizada.

5. Armazenamento e Segurança

  • Os dados clínicos são armazenados em banco de dados SQLite no servidor da aplicação, protegido por criptografia em trânsito (HTTPS/TLS)
  • O acesso ao App é protegido por senha
  • Não compartilhamos, vendemos ou transferimos dados pessoais a terceiros
  • Dados de pacientes são tratados de acordo com a ética médica e sigilo profissional previstos no Código de Ética Médica (CFM)

6. Retenção de Dados

Os dados clínicos inseridos no App são retidos enquanto o profissional mantiver o uso do aplicativo. O usuário pode solicitar a exclusão de seus dados a qualquer momento entrando em contato com o desenvolvedor.

7. Direitos do Usuário

Em conformidade com a Lei Geral de Proteção de Dados (LGPD — Lei nº 13.709/2018), você tem direito a:

  • Acessar seus dados pessoais
  • Solicitar correção de dados incompletos ou desatualizados
  • Solicitar exclusão de dados
  • Revogar o consentimento para uso dos dados
  • Obter informações sobre o compartilhamento de dados

8. Cookies e Tecnologias de Rastreamento

O NeuroPed Escalas NÃO utiliza cookies de rastreamento, pixels de monitoramento ou tecnologias de publicidade. Não há integração com redes de anúncios ou plataformas de analytics de terceiros.

9. Menores de Idade

O App é uma ferramenta profissional destinada a médicos e profissionais de saúde. Não é destinado ao uso direto por menores de idade. Os dados de pacientes pediátricos são inseridos e gerenciados exclusivamente pelo profissional de saúde responsável.

10. Alterações nesta Política

Podemos atualizar esta Política de Privacidade periodicamente. Notificaremos os usuários sobre alterações significativas por meio do App. A data de última atualização estará sempre visível no topo deste documento.
