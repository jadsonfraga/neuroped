# Histórico de documentação

Relatórios de auditoria, planos, QA e notas de arquitetura **históricos/de trabalho**,
movidos da raiz do repositório para reduzir o ruído e elevar a legibilidade.

Estes documentos são registro de processo — **não** são a documentação canônica.
A documentação viva fica na raiz e em `docs/`:

- Raiz: `README.md`, `ARCHITECTURE.md`, `KNOWN_LIMITATIONS.md`, `DEPLOY.md`,
  `DEPLOYMENT.md`, `SECURITY.md`, `PRIVACY_AND_LGPD.md`, `GO_LIVE_CHECKLIST.md`,
  `SUPABASE.md`, `CONTRIBUTING.md`, `CHANGELOG.md`.
- `docs/`: regras críticas, auditoria contínua e checklist LGPD.

Nada aqui é referenciado por CI, testes ou pelo app — é memória do projeto.
