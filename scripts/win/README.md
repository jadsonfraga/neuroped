# Scripts auxiliares Windows (`.bat` / `.ps1`)

Automação local de conveniência (merge/push/deploy manual) movida da raiz.
**Não** são usados pela CI nem pelo build — são atalhos do fluxo local do autor.

Execute-os a partir desta pasta. Caminhos relativos internos assumem que o
repositório está no diretório de trabalho atual; rode da raiz se necessário
(ex.: `scripts\win\MERGE-LOCAL.bat`).
